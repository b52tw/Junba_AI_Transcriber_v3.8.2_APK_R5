R5 首次實機測試順序
====================
1. 建議先完整解除安裝舊 R4/R4.1 診斷版，再安裝 R5。
2. 點 App：R5 安全啟動頁應只短暫出現，之後自動進入完整轉錄畫面。
3. 完整畫面先停留 20–30 秒，不操作，確認不再因 ScrollBarDrawable 閃退。
4. 測 Gemini API Key。
5. 用 1–3 分鐘短音檔測 Gemini。
6. 再測 Whisper tiny/base。
7. 再測自動混合。
8. 最後測長音訊、逐字稿預覽與「儲存本次」。

若完整功能仍異常返回 R5 安全頁：
按「複製最近診斷」，把全文貼回即可。
